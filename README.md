# CSE421 – Embedded Machine Learning Homeworks

Bu repository, **CSE421 Embedded Machine Learning** dersi kapsamında yapılan ödevleri içermektedir.  
Çalışmalar STM32F746G-DISCO geliştirme kartı, Mbed Studio, CMSIS-DSP kütüphanesi ve Python tabanlı sinyal işleme araçları ile gerçekleştirilmiştir.

Her ödev, kendi klasörü içinde **kodları**, **veri dosyalarını** ve **raporunu (PDF/README)** içerir.
